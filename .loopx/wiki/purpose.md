# EricStack Purpose

## Project Goal

Build the most effective AI-native engineering loop — where AI handles not just coding but the entire lifecycle of: planning, review, simplification, documentation, and knowledge accumulation.

## Key Questions

1. How do we ensure every engineering decision is captured and compounding?
2. How do we maintain code quality without slowing down shipping?
3. How do we build institutional knowledge that survives individual sessions?
4. How do we make the AI loop feel like a senior engineer partner, not a chatbot?

## Scope

**In scope:**
- LoopX skill system (46 skills: 13 process + 32 ability + 1 router; 5 ability skills vendored from mindmux/brain.md for project-level persistent memory)
- Agent Notes and decision records
- Engineering loop workflows (plan → review → ship → retro)
- Knowledge base (this wiki)

**Out of scope:**
- Direct code implementation (handled by user / other tools)
- Infrastructure provisioning
- Deployment automation (beyond skill recommendations)

## Evolution

This purpose file is co-maintained by human and LLM. When project direction changes, update this file first, then update the corresponding concepts and entities.
