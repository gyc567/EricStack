# Doc Site Sync

> Process concept page — part of EricStack discipline layer

## Overview

文档站同步流程，确保 VitePress 文档与源码保持一致。涉及 build、deploy、link check 三个环节。

## When to use

Invoke via `/erics-process-doc-site-sync` when working on related tasks.

## Key principles

- Follow the closed-loop rule: every invocation produces a verifiable output
- Document decisions made during the process in the wiki
- Escalate to higher-tier skills when scope exceeds this process
